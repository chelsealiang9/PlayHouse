# PlayHouse
 lounge room for a smiski!
This is a lounge room that I created. It is meant to be a bit abstract but flowy at the same time, so a things like the couch or cushion are curved and smooth. I got the idea from some modern homes online that also have a similar design concept and incorporate nature as well. I tried to make the colors more earthy and natural to represent that connection with nature (and the smiski fits that too!)
